### 과제 진행 순서

모든 기능은 아래 흐름으로 진행해요. 

1. 각 기능의 프롬프트 예시를 참고해 AI에게 기능 구현을 요청해요
    
    0단계에서 전달한 맥락을 바탕으로, 기능 단위로 끊어서 요청해요. 한 번에 모든 기능을 요청하기보다 하나씩 구현하고 확인하는 방식으로 진행해요.
    
2. ⭐**AI가 생성한 코드를 이해하고 수정해요**⭐ 
    
    AI가 짠!하고 만들어준 코드를 그대로 사용하는 것은 지양해야 합니다. 사용하기 전에, **어떤 방식으로 구현됐는지 흐름을 파악**해요. 좋은 개발자는 코드를 빠르게 작성하는 사람이 아니라, **코드를 정확하게 읽고 이해하는 사람**이에요. 
    
    AI가 코드를 쉽게 작성해주는 시대일수록, **생성된 코드를 읽고 이해하는 능력이 더 중요한 개발자의 역량**이라는 점 잊지마세요!
    
3. 로컬에서 직접 실행하고 의도대로 동작하는지 확인해요.
    
    `npm run dev` 로 실행 후 브라우저에서 직접 확인해요. 
    
4. 원하는 대로 동작하지 않거나 에러가 발생하면 AI와 함께 디버깅해요
    
    에러 메시지와 현재 코드를 함께 AI에 전달하면 더 정확한 원인과 해결 방법을 얻을 수 있어요
    
5. 다음 문서를 확인하고, **Issue 템플릿에 맞추어** 기능 단위 별로 진행한 태스크를 기록하며 진행해요
    
    **👉 Issue 템플릿 확인하러 가기**

**다시 한 번 강조! AI가 만들어준 코드 그냥 쓰면 안되나요?**

AI가 생성한 코드를 직접 읽고 이해하는 걸 넘어서 직접 읽고 수정해보는 과정이 중요한 이유는 세 가지예요.

- **코드를 이해해야 다음 단계로 나아갈 수 있어요.** 이번 과제의 코드는 다음 과제(React, Next.js)에서 같은 기능을 다시 구현하는 기반이 돼요. 지금 코드를 이해하지 않고 넘어가면 이후 과제에서 더 어려워질 수 있어요.

### **2. 문제 해결을 위한 디버깅 방법이 궁금해요**

디버깅(Debugging)이란 트러블 슈팅 과정에서 코드 레벨로 들어가 구체적인 원인을 찾고 수정하는 행위예요. 쉽게 말하면, “기능이 등작하지 않네?”는 트러블 슈팅이고, “콘솔을 열어 어느 코드에서 문제가 발생했는지 찾아보자!”가 디버깅이라고 할 수 있어요.

개발자라면 누구나 디버깅을 반복하면서 코드를 완성해나가요. 다양한 디버깅 방법에 대해 알아봅시다.

- **STEP 1 : 브라우저 개발자 도구 열기**
    
    가장 먼저 브라우저에서 마우스 우클릭을 한 후  `개발자 도구(F12)`를 클릭한 후 `Console` 탭을 확인해보세요. 개발자 도구는 디버깅에서 가장 많이 사용하는 도구예요.  
    
- **STEP 2 : 에러 메시지 확인하기**
    
    코드에서 에러가 발생하면 `Console` 탭에 빨간색 메시지로 표시돼요. 에러 메시지를 클릭하면 문제가 발생한 코드 위치로 바로 이동해요. 에러 메시지 오른쪽에는 `pen.js:5`처럼 파일명과 줄 번호가 함께 표시되는데, 이 숫자가 문제가 생긴 줄 번호예요.
    
    !image.png
    
    에러 메시지와 위치를 파악했다면, 해당 코드를 살펴보세요. 자주 발생하는 에러 메시지는 아래와 같아요.
    
    | **에러 메시지** | **의미** |
    | --- | --- |
    | `Cannot read properties of null` | HTML에서 해당 요소를 찾지 못했을 때 (id나 class명 오타 확인) |
    | `is not defined` | 선언되지 않은 변수나 함수를 사용했을 때 (오타 확인) |
    | `Unexpected token` | 괄호나 중괄호가 열리고 닫히지 않는 등 문법 오류가 있을 때 |
- **STEP 3 : `console.log`로 값 확인하기**
    
    에러는 없는데 동작이 이상하다면 코드에서 `console.log` 를 활용해 코드가 어떤 값을 가지고 있는지 직접 찍어볼 수 있어요.
    
    `Console` 탭에서 출력된 값을 보고 내가 예상한 값과 어떻게 다른지 비교해보세요.
    
    ```jsx
    console.log('현재 투두 목록:', todos);
    console.log('선택된 날짜:', selectedDate);
    ```
    
- **STEP 4 : AI에게 도움 요청하기**
    
    원인을 찾기 어렵다면 에러 메시지와 코드를 AI에게 그대로 전달해요. 이때, 에러 메시지와 현재 코드를 함께 전달하면, 더 명확한 원인과 해결 방안을 알 수 있어요.
    
    ```
    아래 에러가 발생했어. 현재 코드를 보고 원인과 해결 방법을 알려줘.
    
    [에러 메시지]
    에러 메시지 붙여넣기
    
    [현재 코드]
    코드 붙여넣기
    ```
    

### **3. 새로고침하면 데이터가 사라져요**

이 경우에는 다음 내용을 확인해보세요.

- **STEP 1 : 브라우저 개발자 도구 열기**
    
    가장 먼저 브라우저에서 마우스 우클릭을 한 후 `검사` → `개발자 도구(F12)`를 클릭한 후 `Application` 탭을 확인해보세요. 개발자 도구는 디버깅에서 가장 많이 사용하는 도구예요.  
    
- **STEP 2 : Local Storage 확인하기**
    
    좌측 패널의 `Storage` → `Local Storage` → `현재 주소` 를 클릭하여 저장된 키(key)와 값(value)이 있는지 확인해요. 아래와 같이 비어있다면, 로컬 스토리지에 데이터가 저장되고 있지 않는 거예요!
    
    !스크린샷 2026-04-28 오후 2.56.52.png
    
    로컬스토리지는 문자열만 저장할 수 있으므로 객체나 배열을 그대로 저장하면 `[object Object]`처럼 저장되고 있다면, 아래와 같이 `JSON.stringify`, `JSON.parse`를 사용하고 있는지 확인해요.
    
    ```jsx
    // 저장할 때
    localStorage.setItem('todos', **JSON.stringify**(todos));
    
    // 불러올 때
    const todos = **JSON.parse**(localStorage.getItem('todos')) || [];
    ```
    

### **4. 날짜가 맞지 않거나 이상하게 표시돼요**

JavaScript의 `Date` 객체는 기기의 로컬 시간을 기준으로 동작해요. 날짜를 비교하거나 저장할 때는 아래처럼 문자열 형태로 통일해서 사용하는 것이 혼란을 줄일 수 있어요.

```jsx
// 날짜를 문자열로 변환해서 저장하고 비교해요
const today = new Date().toISOString().split('T')[0]; // "2024-01-01"
```
